Project Management

Complete Guide to Managing Business Projects and Tasks

Overview

The Project Management module enables comprehensive project planning, task management, resource allocation, and progress tracking. Users can create projects, assign team members, set deadlines, manage budgets, track milestones, and generate project reports.

This module is ideal for managing business projects, client engagements, construction projects, software development sprints, and multi-phase initiatives.

Create a New Project

Steps to Create a Project

  1. Navigate to Projects → Projects → New Project as shown in the below image.
    ![Create Project](images/projects/project_create.png)
  2. Fill out the following details in the form that appears:
    [Screenshot: Project creation form]
  1. After Creating the Project
    Click Create. You will be redirected to the View Project page. Here, you'll see:
    • Edit Project: Modify project details.
    • Tasks: Manage all tasks under this project.
    • Milestone: Track major progress points (if enabled).
    ![View Project](images/projects/project_view.png)

📋 General Section

Name
Enter the name of the project (e.g., Website Redesign, Client Onboarding).
Description
Provide a brief overview or purpose of the project. Helps team members understand the goal.
![General Project](images/projects/project_general.png)
Project Type
Classify the project:
  • Internal: Company-internal projects and initiatives
  • Client: Customer-facing projects and deliverables
  • Research: Investigation and development projects
  • Maintenance: Ongoing support and maintenance work
Client/Customer
Link the project to a specific client or internal department. Used for billing, reporting, and communication management.

📅 Additional Information

Project Manager
Assign the team member responsible for managing the project.
Customer
Link the project to a specific customer or client. Useful for client-based work.
Start Date
Choose the date when the project will begin.
End Date
Select the expected date of project completion.
Allocated Hours
Define the total number of working hours expected for the project. Helps in workload planning.
Tags
Add labels to organize and filter projects (e.g., Urgent, Internal, Long-Term).
Company
Select the company under which this project is being managed, if applicable.
![Additional Project](images/projects/project_additional.png)
Project Status
Current project status:
  • Planning: Project being planned and scoped
  • Active: Project in progress
  • On Hold: Temporarily suspended
  • Completed: Successfully finished
  • Cancelled: Terminated before completion

⚙️ Settings

Visibility Options
  • Private: Only invited internal users can see the project.
  • Internal: All internal users can view the project.
  • Public: Internal users and invited external (portal) users can view the project.
Time Management
  • Allow Timesheets: Enable to allow users to log their time against this project.
Task Management
  • Allow Milestones: Enable to track significant phases of the project like design, development, testing, etc.
![Settings Project](images/projects/project_settings.png)

Project Classification Section

Priority Level
Project priority for resource allocation:
  • Critical: Highest priority, urgent delivery
  • High: Important projects with firm deadlines
  • Medium: Standard priority projects
  • Low: Background projects, flexible timelines
Tags
Add tags for categorization: "Marketing", "Development", "Infrastructure", "Client-Work". Enables filtering and search.
💡 Tip:
Complete all project details accurately as they drive resource allocation, reporting, and billing processes.

Task Creation in a Project

Steps to Create a Task

  1. On the View Project page, click Tasks.
  2. Click on the New Task button.
    ![Task Project](images/projects/project_task.png)
  3. Fill out the task creation form:

    📋 General Section

    Title
    Task title (e.g., Design Landing Page, API Integration).
    State
    Task progress state:
    • In Progress
    • Change Requested
    • Approved
    • Cancelled
    • Done
    Tags
    Add tags or create new ones using (+) button to label or group tasks.
    Description
    Provide a detailed explanation of the task.
    ![Task General](images/projects/project_task_general.png)

    ⚙️ Settings Section

    Project
    Select the project this task belongs to. Defaults to the current project.
    Customer
    Link to a customer, if applicable.
    Assignees
    Choose users responsible for this task. The task becomes visible in their dashboard.
    Deadline
    Set the task completion date.
    Allocated Hours
    Estimate time required for the task.
    ![Task Settings](images/projects/project_task_setting.png)
  1. Click Create to save the task. You will be redirected to the View Task page.

On View Task Page

  • Edit Task: Modify the task details.
  • Delete: Permanently remove the task.
  • Sub Tasks: Click to create smaller, trackable items within this task.
![Task View](images/projects/project_task_view.png)

Time Tracking

Logging Time on Tasks

  1. From a task view, click Log Time or access the time tracking interface.
    [Screenshot: Time logging interface]
  2. Enter time details and descriptions.
    [Screenshot: Time entry form]
  3. Click Save to record the time entry.

Time Entry Fields

Date
Date when the work was performed. Defaults to today but can be adjusted for retrospective entries.
Hours Worked
Actual time spent on the task (e.g., 2.5 hours, 8 hours).
Work Description
Brief description of what was accomplished during this time period.
Billable/Non-Billable
Specify whether this time should be billed to the client or treated as internal cost.

Generating Reports

  1. From the Project Dashboard, click Reports.
  2. Select the desired report type and date range.
  3. Choose filtering options (team members, tasks, etc.).
  4. Generate the report in PDF or Excel format.
  5. Download or email the report as needed.

📋 Use Case Example

Example: You're managing a software development project for a client.

  • Create the project "Client App Development" and assign a project manager.
  • Add tasks like "Frontend Design", "Backend API Development", "Testing", each with different assignees and deadlines.
  • For "Frontend Design", create sub tasks like "Login Screen UI", "Dashboard Layout", etc.
  • Enable Allow Timesheets to track developer time on each task.
  • Track key stages using Milestones like "Design Phase Complete" or "Beta Launch".

This structured approach keeps the team aligned and helps management monitor progress easily.

Marketing Campaign Launch

Marketing team coordinating a product launch campaign:

  • Create project: "Product X Launch Campaign Q2 2026"
  • Set milestones: Campaign strategy approval, creative asset completion, media placement, launch event
  • Assign tasks: Market research, content creation, social media scheduling, PR outreach, event planning
  • Track budgets: Creative costs, media buying, event expenses, personnel time
  • Collaborate: Creative reviews, compliance approvals, vendor coordination
  • Monitor progress: Daily task completion, campaign performance metrics, budget utilization
Construction Project Management

Construction firm managing a commercial building project:

  • Create project: "Office Complex Phase 2 Construction"
  • Define phases: Foundation, structural work, mechanical systems, interior finishing
  • Add team members: Site supervisor, subcontractors, safety officer, quality inspector
  • Track resources: Material deliveries, equipment rental, labor hours, permit status
  • Monitor compliance: Safety inspections, quality checkpoints, regulatory approvals
  • Generate reports: Progress updates for stakeholders, cost analysis, schedule adherence

Best Practices

  • Clear Project Scope: Define project objectives, deliverables, and success criteria upfront to avoid scope creep.
  • Regular Check-ins: Schedule periodic team meetings and progress reviews to maintain project momentum.
  • Task Granularity: Break large tasks into smaller, manageable pieces with clear ownership and deadlines.
  • Communication Standards: Establish guidelines for how team members should update task status and communicate issues.
  • Resource Planning: Accurately estimate time and resources needed to avoid overcommitment and ensure quality delivery.
  • Risk Management: Identify potential project risks early and develop mitigation strategies.
  • Documentation: Maintain clear project documentation for reference, handoffs, and future similar projects.
Summary

Projects module in FrogmenDash allow for efficient management of tasks, deadlines, and team collaboration. By utilizing features like task assignments, sub tasks, milestones, and timesheets, organizations can streamline their project workflows and ensure successful project delivery.
