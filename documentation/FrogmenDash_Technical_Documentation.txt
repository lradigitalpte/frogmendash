FrogmenDash - Technical Documentation
Enterprise ERP & ROV Inspection Platform


SYSTEM OVERVIEW

FrogmenDash is a comprehensive Enterprise Resource Planning (ERP) and Remote Operated Vehicle (ROV) inspection management platform built with modern web technologies. The system provides integrated solutions for business management, inspection workflows, and operational efficiency.

Version: 1.0.0 | Framework: Laravel 11.48.0 | PHP: 8.2.12 | Environment: Production Ready

DATABASE SCHEMA

ROV Inspection Module
Tables: rov_projects, project_structures, inspection_points, inspection_media
Relationships: Hierarchical project → structure → points → media
Features: Media management, GPS coordinates, inspection workflows

Accounting Module
Tables: accounts, journals, invoices, payments
Relationships: Chart of accounts with journal entries
Features: Double-entry bookkeeping, financial reporting

Inventory Module
Tables: products, inventory_items, stock_movements
Relationships: Product → inventory → movements tracking
Features: Stock levels, movement history, valuation

Sales & Purchases Module
Tables: quotations, orders, purchase_orders
Relationships: Customer/supplier order management
Features: Order lifecycle, approval workflows, invoicing

User Management Module
Tables: users, roles, permissions, model_has_roles
Relationships: Spatie permission system integration
Features: RBAC, tenant isolation, audit trails
